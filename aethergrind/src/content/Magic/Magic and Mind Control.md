While in a lot of worlds there is a set school of magic for controlling people's emotions, minds, etc. (enchantment magic), but in Aein there is not a single school and the idea of influencing a person's thoughts, memories, actions, and so on, can be achieved through a number of ways.

**Annimation**. Aura has a link to the mind. A person's will can help to shape the aura around them, as seen in Ethological spell casting. It can then be assumed that if the mind can shape aura, aura can shape the mind. Annimation takes this and with careful manipulation of the aura around a person you can make them feel certain ways or think certain things. This is not total mind control, but much more subtle, more like influence than control.
**Transmutation**. Where Annimation may subtly shape a person's thoughts, Transmutation changes the biology of a person's brain. Influencing a person via transmutation is more akin to a mad scientist putting electrodes in a person's brain to make their mouth salivate. This magic is extremely hard to master, but if done correctly it can be used to permanently alter a person's psychology.
**Theurgy**. The mechanics by which theurgical spells work on a person is not fully known.
